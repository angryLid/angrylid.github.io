# 文生图任务

你需要根据下面描述生成四幅示意画像。要求

- 画面的比例必须是严格的，长宽比例必须是 1:1 的正方形
- 画面应该完整铺满。不要加框线和留白
- 画风会比较像是典型的卡牌游戏的人物卡或者怪物卡，请你参考经典卡牌「游戏王」的风格。但是你务必注意只要绘制人物立绘 **不要** 出现卡片的框。
- 画面中不会出现任何对话。
