# 一些 API 供应商的使用体验

以下按时间顺序排序。

## 火山方舟

| 维度 | 体验 |
| --- | --- |
| 模型 | 主要是 GLM、MiniMax、DeepSeek、Seed（也就是豆包）、Kimi。没有外国模型我能理解，但是没有 Hy3 和千问就说不过去了。 |
| 价格 | 每个月 40 元，第一次开 10 元。该产品需要实名认证，应该不能钻空子重复使用新客优惠。 |
| 用量 | 完全是黑箱，看不到 Token 的用量和调用情况。 |
| 稳定性 | 我没开 sub-agent 也会频繁报 429 调用次数过多。 |
| 总结 | 和字节跳动的实力完全不匹配的一个项目，有首月优惠不妨开通玩玩，10 元必然不亏。 |

## OpenCode Go

| 维度 | 体验 |
| --- | --- |
| 模型 | 开源模型基本都有。 |
| 价格 | 每个月 5 美元，第一次开 5 美元。猜测应该是依赖 Stripe 来判断新用户吧，理论上可以通过换不同支付方式连续享受这个优惠。 |
| 用量 | 没算，但绝对是物超所值了。 |
| 稳定性 | 还行吧。我订阅期间有次宕机但是我没赶上。 |
| 总结 | 5 美元无脑开，10 美元或许再多考虑下。 |

## DeepSeek API

| 维度 | 体验 |
| --- | --- |
| 模型 | 当然，只有 DeepSeek flash 和 pro 两个模型。 |
| 价格 | Token 计价。粗略看了下账单，涨价前用 flash 模型，1 块钱可以烧 12M 以上，涨价以后 8M 以内，如果是忙时就更少了。 |
| 稳定性 | 基本没卡过。 |
| 总结 | v4-flash-0731 涨价前是神，涨价后跌落神坛。 |

## OpenRouter

| 维度 | 体验 |
| --- | --- |
| 模型 | 很多很全，丰俭由人。注意，如需使用美国模型，注册时账单地址不能选中国香港。 |
| 价格 | Token 计价，反正我只能用得起 Luna，拉账单看，单价约为 4.5M/RMB。 |
| 稳定性 | 基本也没卡过。 |
| 总结 | 这个平台应该是口碑尚可的中转站，适合体验各种模型。日用还是肉疼。 |

## Command Code Go Plan

| 维度 | 体验 |
| --- | --- |
| 模型 | 也是开源模型基本都有，加上一些廉价封闭模型。 |
| 价格 | 1 美元，加上 Stripe 高昂手续费实际上是 1.36 美元。 |
| 用量 | 如果全部都用 DeepSeek flash 谷价预计能烧 200M 以上。 |
| 稳定性 | 能明显感觉到 Muse Spark 1.2 这种超便宜的，吐字较慢。GPT Luna 不知道用哪家供应商的接口，吐字有乱码。DeepSeek 似乎是接入官方的，也有峰谷定价。 |
| 总结 | 这个套餐最大的雷点是不可以用 API endpoint，**只能在他们的产品 Command Code 里面用**。适合作为他家 10 美元那个 GOAT Plan 的一个试用评估套餐。 |

## Nube

| 维度 | 体验 |
| --- | --- |
| 模型 | 目前就 DeepSeek flash 和 GLM。 |
| 价格 | Token 计价。1 块钱只能用DeepSeek flash 的 4M Token，令人费解，或许是缓存命中率远不如官方。 |
| 稳定性 | 吐字比官方要慢一点。 |
| 总结 | 要不是因为之前买 VPS 剩的一些余额根本不可能用这个。 |
